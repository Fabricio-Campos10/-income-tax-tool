# Ferramenta de Imposto de Renda

## 📌 Sobre o projeto

Este projeto consiste em uma ferramenta desenvolvida no **Microsoft Excel** para organizar e centralizar informações financeiras utilizadas na preparação da declaração de Imposto de Renda.

A planilha foi estruturada para facilitar o registro dos **dados pessoais do contribuinte, informações bancárias, rendimentos e documentos de apoio**, mantendo todas essas informações organizadas em um único arquivo.

## 🗂️ Estrutura do projeto

O arquivo é dividido em quatro abas principais:

### 👤 Titular

Reúne os dados pessoais e informações cadastrais do contribuinte, como nome, CPF, endereço, telefone e e-mail.

### 🏦 Informes

Permite registrar informações de diferentes instituições financeiras, seus respectivos saldos e os documentos utilizados como comprovantes. Os valores são consolidados automaticamente por meio de fórmulas do Excel.

### 💰 Notas

É utilizada para registrar os rendimentos recebidos, informando a **data, categoria e valor** de cada lançamento. As categorias são padronizadas para evitar erros e manter os dados organizados.

### 📋 Tabelas

Contém informações de referência, como uma lista de instituições financeiras, utilizada para manter a padronização dos dados inseridos na ferramenta.

## ⚙️ Recursos utilizados

O projeto utiliza recursos do Excel para tornar o preenchimento mais organizado e reduzir tarefas manuais, incluindo:

* Fórmulas para cálculos automáticos;
* Validação de dados;
* Listas de opções para padronização das informações;
* Tabelas estruturadas;
* Organização dos dados por categorias;
* Associação de informações a documentos comprobatórios.

## 📊 Aplicação em Data Analytics

Além de funcionar como uma ferramenta de organização financeira, o projeto demonstra conceitos importantes de **Data Analytics**, como estruturação, padronização, validação e consolidação de dados.

A estrutura criada também permite que os dados sejam posteriormente utilizados em ferramentas como **Power BI, Power Query ou Python**, possibilitando análises mais avançadas, como acompanhamento de rendimentos, comparação mensal e criação de indicadores financeiros.

## 🎯 Objetivo

O principal objetivo é transformar informações financeiras dispersas em **dados organizados, padronizados e de fácil consulta**, reduzindo o trabalho manual e facilitando a preparação das informações necessárias para a declaração anual do Imposto de Renda.
