# 📊 Ferramenta de Organização para Imposto de Renda

Este projeto foi desenvolvido no **Microsoft Excel** com o objetivo de criar uma ferramenta que auxilie o usuário na **organização das informações necessárias para a declaração do Imposto de Renda**.

A proposta da planilha é transformar informações financeiras que normalmente ficam espalhadas em diferentes documentos e registros em uma **estrutura organizada, padronizada e de fácil consulta**, facilitando o controle das informações durante o ano e a preparação para a declaração.

## 🎯 Objetivo da planilha

A ferramenta permite registrar e organizar informações relacionadas ao contribuinte, instituições financeiras e movimentações financeiras.

A planilha foi estruturada para que o usuário possa inserir os dados ao longo do tempo e, posteriormente, utilizar essas informações como base para **conferência e preparação da declaração do Imposto de Renda**.

> A ferramenta tem como objetivo auxiliar na organização dos dados e não substitui a análise de um contador ou profissional especializado.

## ⚙️ Como a planilha foi estruturada

O projeto foi dividido em diferentes abas, cada uma com uma função específica:

### 👤 TITULAR

Área destinada ao cadastro das **informações do contribuinte**, mantendo os dados principais centralizados e organizados.

### 🏦 INFORMES

Utilizada para registrar informações presentes nos **informes de rendimentos e documentos fornecidos por bancos e instituições financeiras**.

A planilha utiliza fórmulas para realizar automaticamente alguns cálculos, como a soma dos valores registrados. Dessa forma, quando um valor é alterado, o resultado é atualizado automaticamente.

Um exemplo utilizado no projeto é:

**`=SUM(D11,D16,D21)`**

Essa fórmula soma valores de diferentes posições da planilha, reduzindo a necessidade de cálculos manuais e diminuindo a possibilidade de erros.

### 🧾 NOTAS

Área destinada ao registro das **movimentações e rendimentos**.

Os dados são organizados em formato de tabela, contendo informações como **data, categoria e valor**. Também foram utilizadas opções de validação para padronizar o preenchimento das categorias, evitando que o mesmo tipo de informação seja registrado de maneiras diferentes.

Isso facilita posteriormente a organização e análise dos dados.

### 📚 TABELAS

Aba utilizada como base para informações auxiliares e listas de referência utilizadas pela planilha.

Essa estrutura permite manter determinados dados centralizados e reutilizá-los em outras partes do projeto.

## 🧮 Fórmulas e automação

Um dos principais objetivos do projeto foi reduzir tarefas manuais.

Foram utilizados recursos como:

* **`SUM`** para realizar somas automaticamente;
* **Referências entre células e abas** para conectar diferentes informações;
* **Tabelas do Excel** para organizar os registros;
* **Validação de dados** para padronizar categorias;
* Fórmulas automatizadas para atualizar resultados conforme novos dados são inseridos.

Assim, o usuário precisa principalmente **alimentar a planilha com os dados**, enquanto os cálculos e resultados são atualizados automaticamente.

## 🎨 Formatação e organização

A formatação foi pensada para tornar a utilização da ferramenta simples e intuitiva.

Foram utilizados:

* Diferenciação visual entre campos de preenchimento e resultados;
* Formatação de valores monetários;
* Títulos e cabeçalhos;
* Organização das informações em tabelas;
* Cores para facilitar a identificação das diferentes áreas;
* Padronização das células;
* Estrutura separada por finalidade.

Além de deixar a planilha visualmente mais organizada, essa estrutura facilita a **leitura, conferência e manutenção dos dados**.

## 📊 Aplicação de Excel e Data Analytics

Embora o projeto tenha como finalidade a organização do Imposto de Renda, ele também demonstra a aplicação prática de conceitos de **Excel e Data Analytics**.

O fluxo utilizado pode ser resumido em:

**Entrada de dados → Organização → Padronização → Cálculos → Conferência → Informação**

Dessa forma, informações financeiras inicialmente desorganizadas são transformadas em dados estruturados e mais fáceis de analisar.

## 🚀 O que este projeto demonstra

Este projeto demonstra conhecimentos práticos em:

* Excel;
* Organização e tratamento de dados;
* Fórmulas e funções;
* Tabelas estruturadas;
* Validação de dados;
* Automatização de cálculos;
* Formatação de planilhas;
* Organização de informações financeiras;
* Aplicação de conceitos de Data Analytics em situações reais.

O principal objetivo foi desenvolver uma ferramenta **simples para o usuário, mas estruturada tecnicamente**, mostrando como o Excel pode ser utilizado para transformar registros financeiros em informações organizadas e úteis para a preparação da declaração do Imposto de Renda.

Observação: o projeto possui finalidade educacional. As projeções dependem das premissas utilizadas e não representam garantia de rentabilidade ou recomendação individual de investimento.
